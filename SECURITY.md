# Security Policy

## Supported Versions

We actively maintain and provide security updates for the following versions of **Samast Cron**:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **Samast Cron** very seriously. If you discover a security vulnerability or potential issue, please **do not create a public GitHub issue**.

Instead, please report security issues directly to the maintainers via:
- **Email**: `security@samast.pro`
- **Private Disclosure**: Submit a security advisory via [GitHub Security Advisories](https://github.com/kachakaran6/cron/security/advisories/new)

### What to include in your report:
- Type of issue (e.g., SSRF bypass, SQL injection, authentication bypass)
- Step-by-step instructions or proof of concept to reproduce the issue
- Affected components (`apps/api`, `apps/worker`, `apps/web`, etc.)
- Impact of the issue

### Response Timeline:
- **Acknowledgement**: Within 48 hours.
- **Triage & Patch**: High severity issues are triaged and patched within 7 business days.
